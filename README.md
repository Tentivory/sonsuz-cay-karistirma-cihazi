# Sonsuz Çay Karıştırma Cihazı

## Resmi Açıklama

Bu proje, insanlık tarihinin en büyük ve aynı zamanda en anlamsız teknolojik atılımıdır.  
**Sonsuz Çay Karıştırma Cihazı**, çayınızı sadece karıştırmakla kalmaz; çayın varoluşsal krizini, şekerin kaderini ve kaşığın özgür iradesini sorgulayan bir felsefi aygıttır.

Çay soğusa da, bardağınız kırılsa da, siz başka odaya geçseniz de, hatta çay hiç olmasa da — cihaz karıştırmaya devam eder.  
Çünkü **prensip budur**.

## Özellikler

- Sonsuza kadar çalışır (veya siz Ctrl+C yapana kadar)
- Rastgele şeyleri karıştırır: şeker, hayatın anlamı, komşunun kedisi, varoluşsal boşluk
- Saat yönünde, tersine, kaotik veya hiçbir yönde karıştırma yeteneği
- Ara sıra derin felsefi yorumlar yapar
- Çayınızı mahvetme garantisi %100
- Enerji tüketimi: bir fincan çayın moral bozulması kadar

## Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/sonsuz-cay-karistirma-cihazi.git
cd sonsuz-cay-karistirma-cihazi
python karistir.py
```

Cihazı durdurmak için Ctrl+C yapın. Yoksa sonsuza kadar karıştırır.  
Sorumluluk size aittir. Çayınız soğursa şikayet etmeyin.

## Uyarı

Bu cihaz bilimsel olarak kanıtlanmamış, tıbbi olarak onaylanmamış ve mantıken tamamen gereksizdir.  
Kullanımı sırasında oluşabilecek her türlü çay kaynaklı travmadan proje sahibi sorumlu değildir.

## Lisans

Özgürce kullanın. Ama karıştırın. Karıştırmadan gitmeyin.
